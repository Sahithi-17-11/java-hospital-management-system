# Java Hospital Management System

A console-based Hospital Management System developed using Java.  
This project helps manage basic hospital operations such as patients, doctors, appointments, and billing.

---

## Features

- Patient Module  
  - Add patient details  
  - View patient details  

- Doctor Module  
  - Add doctor details  
  - View doctor details  

- Appointment Module  
  - Book appointments  
  - View appointments  

- Billing Module  
  - Generate bills  
  - View total bill amount  

---

## Technologies Used

- Java
- VS Code
- Git & GitHub
